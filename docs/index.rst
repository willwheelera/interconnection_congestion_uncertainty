AMPS Documentation
==================

This documentation covers the analysis code in the ``code/`` directory of the
AMPS research project. The project uses `EGRET
<https://github.com/grid-parity-exchange/Egret>`_ for electricity-market
optimization and provides both analytical and numerical methods for studying how
Locational Marginal Prices (LMPs) respond to power injections.
